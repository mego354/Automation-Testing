Automated Testing Workflow

Complete Testing Process

The app performs comprehensive automated testing of Android APK files using a sophisticated workflow that captures every aspect of the testing process.

Setup & Launch

  • AVD Launch: Starts Android Virtual Device (emulator)
  • Appium Connection: Connects to Appium server (localhost:4724)
  • APK Installation: Installs the uploaded APK on the emulator
  • Driver Initialization: Sets up UIAutomator2 automation driver

Recording & Analysis

  • Screen Recording: Starts video recording (60 FPS)
  • Initial Screenshot: Captures first screen state
  • UI Hierarchy: Extracts complete XML structure
  • Button Detection: Finds first clickable button

Interaction & Testing

  • Button Click: Automatically clicks the first clickable button
  • Wait Period: Waits 5 seconds for UI changes
  • Second Screenshot: Captures screen after interaction
  • Change Detection: Compares before/after UI states

Cleanup & Results

  • Home Navigation: Returns to home screen
  • Stop Recording: Ends video capture
  • App Uninstall: Removes APK from emulator
  • Result Storage: Saves all media and data

Technical Implementation

Appium Automation

Uses Appium 2.0 with UIAutomator2 driver for Android automation. Connects to local Appium server and controls the Android emulator programmatically.

Element Detection

Recursively searches the UI hierarchy to find the first clickable button with a valid resource ID, ensuring reliable interaction.

Data Storage

All test results, media files, and metadata are stored in MySQL database with Django's file handling system for easy retrieval and analysis.

Complete Application Workflow

1. Setup & Configuration

Configure Android Virtual Device (AVD) and Appium server connection. Set up database and email credentials for the Django application.

2. APK Upload & Management

Users can upload APK files through the web interface. The system stores metadata and file information in the database with unique slugs.

3. Automated Testing Process

Appium launches AVD, installs APK, starts recording, captures initial screenshot, finds first clickable button, clicks it, captures second screenshot, and stops recording.

4. UI Analysis & Detection

The system extracts complete UI hierarchy XML, recursively searches for clickable elements, and compares before/after states to detect changes.

5. Media Capture & Storage

All test results including video recordings (MP4), screenshots (PNG), and UI hierarchy (XML) are stored in MySQL database with Django's file handling.

6. Accessibility & Internationalization

Built-in accessibility features include high contrast mode, font size adjustment, and multi-language support (English/French) with Django i18n.

Key Testing Features

Automated Button Detection

The system automatically finds the first clickable button in the app's UI hierarchy by recursively searching through XML elements with clickable="true" and valid resource IDs.

Before/After Screenshots

Captures screenshots before and after the button click to visually document the UI changes and test results for analysis and debugging.

Screen Recording

Records the entire testing process at 60 FPS, providing a complete video documentation of the automated test execution from start to finish.

UI Hierarchy Extraction

Extracts and stores the complete XML structure of the app's UI elements, enabling detailed analysis of the application's interface structure.
